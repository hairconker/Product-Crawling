# 阶段 8 · 硬件字典工程 · 需求锁定

> 周期：第 17 天（本阶段产物即本文档 + 项目记忆条目，不产代码）
> 目标：冻结"DIY 台式机硬件字典 + 每周价格快照"初始化并行工作流的**范围、动机、数据源分工、输出结构、刷新策略**，后续阶段 9-13 以此为契约。

---

## 背景与动机

原 `run_cpu_crawl_pw.py` 仅做"用户传入关键词 → 三平台爬价格"，缺少"**要搜哪些关键词**"的上游字典。2026-04 确认：
- 用户需要监测二手市场价格，DDR3 时代起的老硬件（2015+）因近期涨价重新有交易价值
- 阶段 2 搜索词使用**完整 SKU 全名**（如 `ROG-STRIX-RTX4090-O24G-GAMING`）而非芯片名，提高精度
- 默认**每周**刷新一次字典 + 价格

## 锁定的需求

### 1. 品类范围（仅 DIY 台式机内部件）

| 品类 | 一级字典（芯片/规格）| 二级字典（厂商 SKU 全名）|
|---|---|---|
| CPU | 具体型号（i5-12400F）| — |
| 主板 | 芯片组（B760 / X670E / Z97 等）| 厂商具体型号 |
| 显卡 | 芯片型号（RTX 4090 / GTX 1080 / RX 6600 等）| 厂商 SKU（公/非公版）|
| 内存 | 规格（DDR5-6000-32G / DDR3-1600-8G）| 品牌型号 |
| SSD | 接口+容量（M.2 NVMe 1T）| 品牌型号 |
| HDD | 容量+转速 | 品牌型号 |
| 电源 | 瓦数+认证（850W 金牌）| 品牌型号 |
| 散热器 | 具体型号 | — |
| 机箱 | 具体型号 | — |
| 网卡 | 具体型号（AX210）| — |

**排除**：显示器 / 键鼠 / 音箱 / 整机 / 迷你主机 / 笔记本 / 光驱 / 风扇 / 硅脂（未来可补）。

### 2. 时间下界：2015 年起

- GPU：GTX 900 / Radeon R200 及以后
- CPU：Intel Haswell / AMD FX 及以后
- 芯片组：H81 / Z97 / A88X 及以后
- 内存：DDR3-1333 及以后

**动机**：2026 年旧硬件涨价（DDR3 内存翻倍、GTX 10 系二手活跃），这些型号需要被监测。

### 4. 数据源分工

| 层 | 数据源 | 实现方式 |
|---|---|---|
| 一级字典（芯片/规格）| `docyx/pc-part-dataset`（北美，MIT，66k SKU）| 阶段 9 clone 到 `vendor/`，解析归一化 |
| 国际品牌 SKU 全名 | 同上 | 阶段 9 同时输出 |
| 国行/国产品牌 SKU 全名 | **京东自营分类页**（影驰/七彩虹/铭瑄/万丽/玄派等）| 阶段 10 自写 `spiders/dict_jd_category.py` |
| 新型号兜底（docyx 滞后 3-6 月）| `data/dict/overrides/` 用户手填 | 阶段 11 合并时生效 |
| 价格采集（三平台）| 现有 `run_cpu_crawl_pw.py` | 阶段 12 改造，从字典读搜索词 |

### 5. 刷新策略

- **字典**：每周一次（周一凌晨），大部分周没有真变化但保留流水
- **价格**：每周一次，默认"热门品类"全跑（GPU/CPU/内存/SSD/主板），冷门（HDD/散热/机箱/电源/网卡）按需手动触发
- **归档**：滚动保留 12 周，更早的周自动打 zip 到 `data/archive/`
